点名器 · 使用说明

一个基于 Vibe Runtime 2.1 的随机点名插件，支持多名单、隐藏权重、专属视频/背景，以及原神式保底机制。

---

一、简介

点名器从 assets/lists/ 下的文本文件读取名单，每次点击「开始点名」会按权重随机抽取一个名字，并用视频遮挡抽取过程，最后展示结果。

核心特性：

· 多名单：可同时存在多个班级 / 抽奖池，顶部标签切换。
· 隐藏权重：名单里可以给每个人设权重，界面完全看不出来。
· 专属素材：抽中特定人时可播放专属视频、展示专属背景。
· 金标记：用 ！ 或 #!gold 标记“金”角色。
· 保底机制：可设置 N 抽必出金，甚至指定必出某个人名。
· 自动回退：专属素材缺失时自动使用默认素材，不会报错。

---

二、安装

1. 把整个 roll-call 文件夹放进运行时的 installed/ 目录：
   ```
   installed/
   └── roll-call/
       ├── manifest.json
       ├── main.js
       ├── style.css
       └── assets/
           ├── default_bg.jpg
           ├── default_video.mp4
           ├── ...（专属素材）
           └── lists/
               ├── index.txt
               ├── class1.txt
               ├── class2.txt
               └── lottery.txt
   ```
2. 刷新页面 → 打开 Plugin Center → 点击「点名器」。
3. 首次运行会自动读取 assets/lists/index.txt 并加载所有名单。

四、快速上手

1. 准备默认素材：放一张 default_bg.jpg 和一段 default_video.mp4 到 assets/。
2. 编辑名单索引 assets/lists/index.txt：
   ```
   class1.txt / 高一(1)班
   class2.txt / 高一(2)班
   ```
3. 编辑名单 assets/lists/class1.txt：
   ```
   张三
   李四
   王五
   ```
4. 刷新插件，顶部会出现「高一(1)班」「高一(2)班」两个标签。
5. 点击右下角「开始点名」，看完视频后显示结果。

五、名单配置详解

5.1 名单索引 index.txt

每行一个名单，格式：

```
文件名 / 显示名称
```

· 文件名 必须是 assets/lists/ 下真实存在的 .txt 文件。
· 显示名称 会出现在顶部标签上，省略时用文件名（去 .txt）。
· # 开头的行是注释，会被忽略。
· 斜杠两边可以有空格，也可以没有：class1.txt/高一(1)班 同样有效。

示例：

```
# 名单索引
class1.txt / 高一(1)班
class2.txt / 高一(2)班
lottery.txt / 年会抽奖池
```

5.2 名单文件格式

每行一个人名，格式：

```
名字 / 权重 / 专属标识
```

· 名字：必填，不能包含斜杠 /。
· 权重：可选，默认 1。数字越大越容易被抽中，支持小数（如 24.4）。
· 专属标识：可选，填了就会在抽中时播放 assets/<标识>_video.mp4 并展示 assets/<标识>_bg.jpg。

斜杠两边可以有空格，也可以没有：

```
张三/5/zhangsan
张三 / 5 / zhangsan
张三/ 5 /zhangsan
```

以上三种写法完全等价。

5.3 权重与概率

权重决定相对概率，不是百分比。假设名单里有 N 个人，权重分别为 w1, w2, ...，则某人被抽中的概率为：

```
p = wi / (w1 + w2 + ... + wN)
```

· 权重越高，概率越大。
· 所有普通人权重为 1 时，每个人概率相等。
· 想让某人概率是普通人的 5 倍，就写 某人 / 5。

注意：权重越小，越难被抽中。这和“给某人加权重 = 提高概率”的直觉一致，但如果你想让某人很难被抽中，就把权重写小（如 0.1）。

5.4 专属素材标识

给某人加专属素材：

```
胡桃 / 24.4 / hutao
```

抽中「胡桃」时：

· 播放 assets/hutao_video.mp4 作为遮挡视频。
· 展示 assets/hutao_bg.jpg 作为结果背景。
· 如果这两个文件不存在，自动回退到 default_video.mp4 和 default_bg.jpg。

5.5 金标记

有两种方式把某人标记为“金”：

方式一：数据行第二段写 ！

```
胡桃 / ！ / hutao          ← 金，权重默认 1，带专属素材
钟离 / ！24.4 / zhongli     ← 金，权重 24.4，带专属素材
纳西妲 / ！                 ← 金，权重默认 1，无专属素材
```

· ！ 和 ! 都可以。
· ！ 后面可以紧接数字指定权重。

方式二：顶部配置行 #!gold

```
#!gold 胡桃
#!gold 钟离
```

· 每行声明一个金角色。
· 名字必须与数据行完全一致。

两种方式可以混用，最终会合并成一个“金集合”。保底触发时会从金集合里抽。

5.6 保底机制

在名单文件顶部用 #!pity 配置：

```
#!pity 90                  → 90 抽必出金（金集合内按权重随机）
#!pity 90 胡桃              → 90 抽必出「胡桃」
#!pity 90 胡桃,钟离         → 90 抽从「胡桃 / 钟离」里按权重抽
#!pity 90 胡桃 钟离 纳西妲   → 空格分隔也支持
```

· 90 是保底抽数，必须是正整数。
· 后面的名字是“保底目标”，可省略。
· 如果写了目标但目标不在名单里，保底时会自动回退到金集合。
· 如果连金集合也是空的，会退回普通加权，不会卡死。

保底计数：

· 每次抽到非金名字，计数 +1。
· 抽到金名字，计数归零。
· 计数达到 保底抽数 - 1 时，下一次抽取强制从目标池中出金。
· 计数按名单独立保存，切换名单互不影响，关闭插件再打开也不会丢失。

5.7 完整示例：lottery.txt

```
# 保底：90 抽必出金集合中的任意一个
#!pity 90

# ── 金 · 用「！」标记，权重 24.4，各带专属素材 ──
胡桃     / ！24.4 / hutao
钟离     / ！24.4 / zhongli
雷电将军 / ！24.4 / raiden
纳西妲   / ！24.4 / nahida

# ── 普通人 · 每人权重 100 ──
张三 / 100
李四 / 100
王五 / 100
赵六 / 100
钱七 / 100
孙八 / 100
周九 / 100
吴十 / 100
郑十一 / 100
王十二 / 100
…（一直写到第 64 人）
```

六、素材准备

文件 用途 必需
assets/default_bg.jpg 普通名字的结果背景 建议提供
assets/default_video.mp4 普通名字的抽取遮挡视频 建议提供
assets/<标识>_bg.jpg 专属结果背景 可选
assets/<标识>_video.mp4 专属遮挡视频 可选

· 图片建议使用 JPG/PNG，尺寸与窗口比例接近（如 16:9）效果最好。
· 视频建议使用 MP4（H.264），时长 3~10 秒。
· 缺失的素材会自动回退到默认素材，不会报错。

七、界面与操作

元素 位置 说明
名单标签 顶部居中 点击切换名单
保底徽章 左下角 显示距保底还差多少抽；就绪时变金色
开始点名 右下角 点击开始抽取
视频遮挡层 全屏 抽取时播放视频，点击可跳过
结果展示 全屏 背景 + 名字

· 抽取过程中「开始点名」按钮会禁用，防止连点。
· 视频播放完毕或点击视频后，自动进入结果展示。
· 结果展示后，再次点击「开始点名」进行下一次抽取。

八、概率与权重参考

以 64 人名单、4 个金、其余 60 人权重 100 为例：

身份 个数 每人权重 每人概率 合计概率
金 4 24.4 ≈ 0.40% ≈ 1.6%
普通人 60 100 ≈ 1.64% ≈ 98.4%

如果你想要不同的概率分布，按公式调整权重即可：

```
目标权重 = 目标概率 × 其他人权重总和 / (1 - 目标概率)
```

常用参考：

· 想让某人概率为 1%，其他人共 99 份，则权重 ≈ 1。
· 想让某人概率为 10%，其他人共 90 份，则权重 ≈ 9。

九、常见问题

Q：名字里可以有斜杠吗？
A：不可以。斜杠是分隔符，名字里出现斜杠会被切分。

Q：权重可以是小数吗？
A：可以，例如 24.4。

Q：全角斜杠 ／ 可以用吗？
A：不可以，必须使用半角 /。

Q：全角感叹号 ！ 和金标记？
A：！ 和 ! 都支持。

Q：为什么没有滚动条？
A：本插件设置为 scroll: false，所有内容都在一屏内展示。

Q：如何重置某个名单的保底进度？
A：在 DevTools Console 中切换到插件 iframe 上下文，执行：

```js
localStorage.removeItem('vibe.plugin.roll-call.pity.lottery.txt');
```

然后刷新插件。

Q：保底目标名字写错了会怎样？
A：保底触发时会自动回退到金集合；如果金集合也为空，则回退到普通加权，不会报错。

Q：切换名单后保底计数会重置吗？
A：不会，每个名单的保底计数独立保存。

十一、更新与扩展

· 增加名单：在 assets/lists/ 新建 .txt，并在 index.txt 里追加一行。
· 修改权重：直接编辑名单文件中的数字，刷新插件即可。
· 增加金角色：用 ！ 标记，或添加 #!gold 配置行。
· 调整保底：修改 #!pity 行，可同时指定目标。
· 更换素材：替换 assets/ 下的图片和视频，保持文件名不变。
